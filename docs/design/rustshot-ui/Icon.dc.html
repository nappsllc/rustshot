App icon & tray icon
Concept: a selection marquee — four corner brackets — around a single accent dot, the "shot". It is the same geometry the overlay already draws (brackets = the selection frame, dot = a handle), so the icon and the UI read as one thing. Everything is a rounded rect, four stroked arcs and a circle, so it rasterizes with the same primitives as the UI and can be regenerated at any size.
Primary · periwinkle dot on slate tile
Size ramp · three tiers of geometry
Large (≥64) uses the 2-unit stroke. Medium (32–48) thickens to 2.5. Small (16–24) goes to 3 with longer arms and a bigger dot so the brackets still read as a frame. Export 512 · 256 · 128 · 64 · 48 · 32 · 24 · 16 for .icns / .ico / hicolor.
