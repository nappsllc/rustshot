A · Narrow selection → toolbar wraps to 2 rows
Rule: if the full single-row width (≈ 646px) exceeds the selection width + 48px, split at the group boundary after history. Row 1: tools + history. Row 2: size/color + actions, right-aligned. A 1px horizontal rule replaces the vertical separator. The bar stays centered under the selection, clamped to the screen with a 12px margin. Below ~260px wide, the bar simply ignores the selection and centers itself on screen.
